TDI WEBSITE - GITHUB PAGES

File utama:
- index.html = halaman utama website TDI
- admin.html = halaman admin

Cara upload:
1. Buat repository baru di GitHub.
2. Upload index.html dan admin.html ke repository.
3. Masuk Settings > Pages.
4. Pilih Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save.
7. Tunggu proses GitHub Pages selesai.

Catatan:
GitHub Pages adalah hosting statis. Jika halaman admin membutuhkan penyimpanan perubahan secara online lintas perangkat, diperlukan backend/database tambahan.
